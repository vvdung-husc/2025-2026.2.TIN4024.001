# Telegram LED Control

Dự án điều khiển LED qua Telegram Bot sử dụng ESP32.

## Tính năng
- Điều khiển LED bật/tắt qua Telegram Bot
- Nhận trạng thái LED hiện tại
- Kết nối WiFi tự động
- Hỗ trợ mô phỏng trên Wokwi

## Cấu hình
1. Tạo Telegram Bot mới qua @BotFather
2. Lấy Bot Token và cập nhật vào `BOT_TOKEN`
3. Lấy Chat ID của bạn và cập nhật vào `CHAT_ID`
4. Cập nhật thông tin WiFi nếu cần
